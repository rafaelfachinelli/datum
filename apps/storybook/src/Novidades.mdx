# Novidades

O que mudou em cada versão do Datum, da mais nova para a mais antiga. Os pacotes `@rafaelfachinelli/datum-tokens` e `@rafaelfachinelli/datum-ui` andam juntos, com uma versão só. Até a 0.3.1 eles se chamavam `@datum/tokens` e `@datum/ui` e só existiam dentro do repositório do portfólio.

| Mudança                                                   | Versão |
| --------------------------------------------------------- | ------ |
| Correção                                                  | patch  |
| Componente, token ou variante nova                        | minor  |
| Algo que quebra quem usa (prop removida, token renomeado) | major  |

## 0.6.0 · 12 de novembro de 2026

- **CodeBlock com código colorido**, como o do shadcn/ui: o `useHighlightedCode` (de `@rafaelfachinelli/datum-ui/highlight`) colore 13 linguagens com o Shiki, nas cores da paleta do Datum, e só colore as linhas novas enquanto o código chega. Só quem usa instala o `shiki`. ([#8](https://github.com/rafaelfachinelli/datum/pull/8))
- **Quebra: animações do Sheet.** As classes `animate-datum-fade-in` e `animate-datum-slide-in-*` saíram: desde a 0.5.0 o Sheet usa transições do Base UI e nada mais as usava. ([#8](https://github.com/rafaelfachinelli/datum/pull/8))

## 0.5.0 · 12 de novembro de 2026

- **Componentes de conversa**, adaptados dos novos componentes de chat do shadcn/ui para os tokens do Datum: **Message**, **Bubble**, **Marker**, **MessageScroller**, **Attachment**, **Trace**, **CodeBlock** (sem realce de sintaxe, para o pacote ficar leve) e **Questionnaire**, mais o **Collapsible**, que o Trace usa. Como os outros, não escrevem texto de interface: o nome do botão de copiar, do botão de ir para o fim, da região de mensagens, o progresso e os botões do questionário vêm por props, no idioma da página. ([#6](https://github.com/rafaelfachinelli/datum/pull/6))
- **Utilitários `scroll-fade` e `shimmer`** no `styles.css` (do shadcn/ui, MIT): bordas que somem em degradê enquanto há mais para rolar e texto que brilha enquanto algo acontece. O brilho para com movimento reduzido. ([#6](https://github.com/rafaelfachinelli/datum/pull/6))
- **Quebra: Base UI no lugar do Radix.** Todos os componentes passaram para o [Base UI](https://base-ui.com). O `asChild` virou `render`: `<Button render={<a href="/" />} nativeButton={false}>` em vez de `<Button asChild><a href="/" /></Button>`, e o mesmo vale para Badge, CalloutTitle e os gatilhos de Sheet e Tooltip. ([#6](https://github.com/rafaelfachinelli/datum/pull/6))
- **Select** recebe `items` (valor → rótulo), para o gatilho mostrar o rótulo da opção escolhida em vez do valor. ([#6](https://github.com/rafaelfachinelli/datum/pull/6))
- **Quebra: RadioGroup e Tooltip.** O RadioGroup não tem mais `orientation`: as quatro setas navegam entre as opções. O `TooltipProvider` recebe `delay` no lugar de `delayDuration`. ([#6](https://github.com/rafaelfachinelli/datum/pull/6))

## 0.4.1 · 25 de outubro de 2026

- **Uso com Next.js** na página dos pacotes no npm: sem `transpilePackages`, o `optimizePackageImports` para carregar só os componentes usados e o script da temporada no layout. Primeira versão publicada pelo GitHub Actions, com prova de origem (provenance).

## 0.4.0 · 25 de outubro de 2026

- **No npm.** O Datum pode ser instalado em qualquer projeto: `npm install @rafaelfachinelli/datum-ui @rafaelfachinelli/datum-tokens`. Precisa de React 19 e Tailwind CSS 4. ([rafaelfachinelli/datum#1](https://github.com/rafaelfachinelli/datum/pull/1))
- **Quebra: novos nomes.** `@datum/tokens` virou `@rafaelfachinelli/datum-tokens`, e `@datum/ui` virou `@rafaelfachinelli/datum-ui`: troque os imports e os `@import` do CSS. Os componentes, as props e as variáveis `--datum-*` não mudaram.
- **Pacotes compilados.** Os pacotes saem em JavaScript com os tipos, um arquivo por componente, o que preserva o `"use client"` no Next.js. Não precisa mais de `transpilePackages`.
- **Repositório próprio.** O código saiu do portfólio para [github.com/rafaelfachinelli/datum](https://github.com/rafaelfachinelli/datum), com o histórico, sob licença MIT. O nome Datum, o logo e a identidade Blueprint não entram na licença.

## 0.3.1 · 20 de outubro de 2026

- **Button e Badge:** o controle `asChild` saiu do painel. Ligado com um texto simples dentro, a história quebrava, porque o `asChild` precisa de um elemento filho para receber o visual. A história **As Link** mostra o uso certo. ([c495efe](https://github.com/rafaelfachinelli/datum/commit/c495efe))
- **Button:** com movimento reduzido no sistema, o indicador de carregamento continua girando, só mais devagar. Ele mostra que algo está acontecendo; não é decoração. ([8c28033](https://github.com/rafaelfachinelli/datum/commit/8c28033))

## 0.3.0 · 19 de outubro de 2026

- **RadioGroup**, em cartões, para escolhas com título e descrição. Nasceu para as perguntas do [Esboço de arquitetura](https://rafaelfachinelli.com/pt-BR/tools/architecture). ([6b4877c](https://github.com/rafaelfachinelli/datum/commit/6b4877c))

## 0.2.0 · 18 de outubro de 2026

- **`@datum/ui`**, os componentes: Button, Badge, Card, Separator, Label, Input, Textarea, Select, Tooltip e os padrões Field, Callout e Stat. ([e1762b4](https://github.com/rafaelfachinelli/datum/commit/e1762b4), [4a9c6f9](https://github.com/rafaelfachinelli/datum/commit/4a9c6f9), [a69e7ba](https://github.com/rafaelfachinelli/datum/commit/a69e7ba))
- **Sheet**, o painel lateral. O [rafaelfachinelli.com](https://rafaelfachinelli.com) troca as cópias do shadcn pelos componentes do Datum. ([51202fd](https://github.com/rafaelfachinelli/datum/commit/51202fd))

## 0.1.0 · 17 de outubro de 2026

- **`@datum/tokens`:** paleta, tema escuro, tipografia, espaço de 4 px e raio de 2 px no formato do W3C DTCG, com as 8 temporadas. Testes de contraste reprovam a build se um par de texto e fundo ficar abaixo do WCAG AA. ([7f667c8](https://github.com/rafaelfachinelli/datum/commit/7f667c8))
- Este Storybook, com os fundamentos e a barra de temporadas. ([c704e3c](https://github.com/rafaelfachinelli/datum/commit/c704e3c))
