# CodeBlock

Um bloco de código ou de saída de terminal, em fonte monoespaçada, com título, botão de copiar, números de linha e linhas marcadas. Não colore a sintaxe: um realce de sintaxe pesa no pacote, e o Datum fica leve. Quem precisar pode colorir as linhas antes e passar como `CodeBlockLine`.

## Partes

| Parte                 | Papel                                                                                                                                         |
| --------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| `CodeBlock`           | A caixa: `variant` (`default`, `danger`) e `size` (`md`, `sm`).                                                                               |
| `CodeBlockHeader`     | Uma linha acima do código: título e ações.                                                                                                    |
| `CodeBlockTitle`      | O nome do arquivo ou da linguagem, com um ícone opcional.                                                                                     |
| `CodeBlockActions`    | Os botões. No cabeçalho, ficam no fim dele; direto no CodeBlock, flutuam no canto e aparecem no hover ou no foco (sempre, em telas de toque). |
| `CodeBlockCopyButton` | Copia `value`. `label` e `copiedLabel` são obrigatórios: o nome do botão antes e depois de copiar, no idioma da página.                       |
| `CodeBlockContent`    | O código. `lineNumbers` numera as linhas, `startLine` escolhe a primeira, `wrap` quebra linhas longas em vez de rolar para o lado.            |
| `CodeBlockLine`       | Uma linha, marcada como `added`, `removed` ou `highlighted`.                                                                                  |
| `CodeBlockFooter`     | Uma linha abaixo: uma nota, um link para a fonte.                                                                                             |

## Código colorido

As cores vêm do `useHighlightedCode`, num ponto de entrada próprio (`@rafaelfachinelli/datum-ui/highlight`): só quem colore código instala o `shiki`. Cada linguagem carrega na primeira vez que aparece (bash, css, diff, html, javascript, json, jsx, markdown, python, sql, tsx, typescript, yaml); as outras ficam sem cor. Enquanto o código chega aos pedaços, só as linhas novas são coloridas. As cores são da paleta do Datum, todas com contraste de 4,5:1 ou mais.

```tsx
const lines = useHighlightedCode(code, 'ts')
<CodeBlockContent lineNumbers>
  {lines.map((line, i) => <CodeBlockLine key={i}>{line}</CodeBlockLine>)}
</CodeBlockContent>
```

## Acessibilidade

- O código recebe foco pelo teclado, para rolar com as setas; a caixa mostra o anel de foco.
- Depois de copiar, o botão troca de nome e uma região `aria-live` anuncia `copiedLabel`.
- As marcas `+` e `−` das linhas não são selecionadas ao copiar, nem os números.
- A cor não é a única pista de uma linha alterada: o `+` e o `−` dizem o mesmo.
