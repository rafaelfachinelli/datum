# Toast

Uma mensagem curta que confirma o que acabou de acontecer e some sozinha, embaixo da tela: no meio no celular, à direita a partir de 640 px. Use para um "feito" que não pede nada de quem lê.

<Canvas of={ToastStories.Default} />

## Como usar

O `Toaster` envolve a página uma vez, com o nome do botão de fechar no idioma dela. Dentro dele, `useToast` mostra uma mensagem de qualquer lugar.

```tsx
export function Layout({ children }: { children: React.ReactNode }) {
  return <Toaster closeLabel="Fechar">{children}</Toaster>
}
```

```tsx
const toast = useToast()
toast.success('Enviado: a mudança vai para o site')
toast.show('A prévia ainda está sendo montada', {
  tone: 'warning',
  description: 'Abra o link em alguns minutos.',
})
```

## Tons

`success` (feito), `neutral` (uma notícia, o padrão), `warning` (algo para olhar) e `danger` (algo que falhou), marcados na borda da esquerda, como no Callout.

<Canvas of={ToastStories.AllTones} />

## Acessibilidade

- O leitor de tela anuncia cada mensagem com educação, sem interromper; uma de tom `danger` é anunciada na hora.
- Cada mensagem tem um botão de fechar com o nome dado em `closeLabel`.
- Com movimento reduzido, a mensagem aparece e some sem deslizar.

## Boas práticas

- Uma frase curta que diz o que aconteceu ("Enviado", "Salvo"), não o que a pessoa fez.
- Nada que a pessoa precise fazer ou ler com calma: isso fica na página, não numa mensagem que some.
- Não use para erro de um campo: o erro fica junto do campo.
